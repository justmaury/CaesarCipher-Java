# Caesar Cipher Encryption in Java

A beginner-friendly Java project that implements the Caesar Cipher encryption technique.

## About the Project

The Caesar Cipher is a classical encryption technique that shifts each letter in a message by a fixed number of positions in the alphabet.

This project takes text and a shift key as input and generates encrypted text.

## Features

- Encrypts uppercase and lowercase letters.
- Supports custom shift keys from 0 to 25.
- Preserves spaces, numbers, and special characters.
- Takes input using Java Scanner.
- Uses a separate method for encryption.

## Technologies Used

- Java
- IntelliJ IDEA
- Git and GitHub

## Example

**Input:**
```text
Enter text to encrypt: attack at dawn
Enter shift key (0-25): 3
```

**Output:**
```text
Encrypted text: dwwdfn dw gdzq
```

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/justmaury/CaesarCipher-Java.git
   ```

2. Open the project in IntelliJ IDEA.
3. Run `CaesarCipher.java`.
4. Enter your text and shift key.
